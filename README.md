# Angular App (with backend)

This folder contains the Angular frontend and a small Express backend that serves the hotel data.

Backend:
- Start the server:

```bash
cd angular-app/server
npm install
npm run start
```

Frontend:
- From `angular-app` run:

```bash
npm install
npm start
```

During development you can run the backend separately (port 3333) and point the frontend requests to `http://localhost:3333/api`.
